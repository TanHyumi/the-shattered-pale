### [Wiki City](Misc/__Welcome%20to%20LegendKeeper__/The%20Realm%20of%20Tutoria/Wiki%20City.md) is a sub-element of the [The Realm of Tutoria](Misc/__Welcome%20to%20LegendKeeper__/The%20Realm%20of%20Tutoria/The%20Realm%20of%20Tutoria.md), a map with a few pins linking to interesting places.

Every LegendKeeper project is made up of '**elements**'. Elements can be accessed and created from the Project Browser on the left.

An element can represent anything, including a person, place, thing, event, a piece of lore, a chapter of a book, etc. They can contain any number of wiki page, map, or whiteboard tabs. Drag and drop elements and tabs to reorder them and nest them under each other.  

* * *

**Here are some things you can do to quickly learn the basics.**
----------------------------------------------------------------

*   **Create a new project**  
    Congrats! You made a new LegendKeeper project!  
    
*   **Type** `/` **in the editor to open the command menu**  
    This lets you format your text and create useful content blocks.  
    
*   **Create a new tab**  
    Click the 'Add Tab' button that appears when you hover this page's title. From here, you can add a new content tab.  
    
*   **Create a new element**  
    Click the Create button at the bottom of the left sidebar to create a new element at the top level.  
    
*   **Type** `@` **to link to other elements**  
    This helps you quickly create a connected world. You can even create new elements from the @-mention menu. If an element has multiple tabs, type a colon (:) after a mention to specify what tab you'd like to link to.  
    
*   **Find the extended options for elements**  
    Press the Element Menu button with three dots in the top right corner. Here you can add tabs, adjust page layout, magically link pages with Auto-link, toggle pin clustering options for maps, and more.  
    
*   **Upload your first map**  
    Add a map tab to this element by pressing the 'Add Tab' button that appears when you hover the title. Click 'Map' on the blank tab screen, 'Add map image', and then select an image to use as a map.  
    
*   **Add your first map pin**  
    Right click on a map and select 'Create element', 'Link element', or drag an element from the Project Browser onto your map.  
    
*   **Use a template**  
    Create a new Element using the create button in the bottom left, and then select a template from the template selector. Any element you drag into the Templates folder in your Project Browser becomes a re-usable template.  
    
*   **Type** `CMD + /`**(Mac) or** `CTRL + /`**(Windows) to find the help dialog from anywhere**  
    You can also click the `?` in the bottom right corner to discover more help options.
